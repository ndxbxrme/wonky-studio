Guide

Artist guide

Use this as the default workflow for building and checking scenes in Wonky Studio.

Start here

Recommended order

  1. Create or open a scene on `Scenes`.
  2. Add images to the scene from the scene page or from `Images`.
  3. In the scene page, click `Analyze with VLM` to generate the initial object list.
  4. Create extra objects where needed and set or refine prompts.
  5. Run `Extract masks`.
  6. Clean masks manually in the mask editor where needed.
  7. Create animations for moving objects if needed.
  8. Author interactions in `Edit actions`.
  9. Add or review dialog in `Transcript library`.
  10. Generate inventory art and pickup frames for keyboard items if needed.
  11. Use `Preview game` to test the flow.

Pages

What each page is for

Scenes

Create scenes, edit objects, run mask extraction, generate inventory art and pickup frames, and open preview.

Images

Move, filter, and reorder scene images. Use this when photos were assigned to the wrong scene or frame order needs fixing.

Variables

Edit built-in system variables and add shared gameplay variables for counters, toggles, and puzzle state.

Transcript library

Create script lines, review translations, generate TTS, upload reviewed takes, and choose which audio will actually play.

Audio library

Manage standalone BGM and SFX assets used by actions.

Global settings

Set the start scene, overlay settings, verbs, and inventory layout.

Health

Check whether local services like segmentation, translation, TTS, and image generation are available.

Masking

Mask and animation tips

  • Use `Browse all scene frames` in the mask editor if you need to paint masks on frames that do not already have one.
  • Use `Scene background` display mode in the mask editor and animation editor to check whether tightly cropped masks reveal unwanted background motion.
  • Use `Combine masks` when an animation needs one consistent mask shape across all frames.
  • Set a `Default frame` for an object when segmentation confuses similar objects. That frame is used for thumbnails, inventory art, and pickup generation.
  • Use the square brush for sharp corners and the round brush for softer organic shapes.

Interactions

Action authoring tips

  • Use the interaction filters by object and trigger type to keep large scenes manageable.
  • Read the step summaries in the action list: they use object names, variable names, and script text instead of raw IDs.
  • Keep scene-level actions for broad setup and per-object actions for direct interactions.
  • Use variables for shared state like “has key”, “drawer opened”, or “current language mode”.

Audio and text

What will play in preview

  • Reviewed audio takes priority over TTS when available.
  • If reviewed audio exists but no take is selected, preview may not play what you expect. Use the script-review page to confirm the selected take.
  • Approved translations are safer than draft ones. The home dashboard highlights referenced lines with unverified translations.
  • The home dashboard also highlights referenced lines that do not yet have selected audio.

If something looks wrong

Quick checks

  • If AI tools fail or feel unresponsive, check `Health` first.
  • If preview looks out of date, use `Refresh` in the preview window.
  • If an inventory art or pickup frame generation fails, the object will be flagged in the scene object list.
  • If images are in the wrong scene or order, fix them in `Images` before spending time on masks or animations.
  • If a scene background seems wrong, check the scene’s `Background frame` setting.

Safety

Backup habit

  • Export the project before major AI generation passes or at the end of each work session.
  • If you are unsure whether a warning matters, stop and ask rather than trying to work around it blindly.
